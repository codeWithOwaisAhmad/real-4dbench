 
# real-4dbench

Extending 4D-Bench (Elhoseiny & Ghanem, ICCV 2025) to real physical occlusion 
events captured with Intel RealSense D435i.

## Status
🔧 Under active development — data collection not yet started

## Pipeline
- Frame extraction (RGB + Depth)
- QA pair management
- Model evaluation: GPT-4o, Gemini, Video-LLaVA, InternVideo2
- Results compilation and analysis
